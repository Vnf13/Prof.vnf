Manual de Instalação e Utilização do JupyterLab com Anaconda

Este manual ensina a instalar o Anaconda, abrir o JupyterLab e criar o primeiro projeto de Análise de Dados em Python.

1. O que é o Anaconda?

O Anaconda é uma distribuição gratuita do Python voltada para Ciência e Análise de Dados. Ao instalá-lo, você já terá diversas ferramentas prontas para uso:

  • Python
  • Jupyter Notebook
  • JupyterLab
  • Pandas
  • NumPy
  • Matplotlib
  • Seaborn
  • Centenas de outras bibliotecas

Isso evita instalar cada biblioteca separadamente.

2. Baixando o Anaconda

Acesse o site oficial: anaconda.com/download

Baixe a versão correspondente ao seu sistema operacional (Windows). Após o download:

  1. Execute o instalador.
  2. Clique em Next.
  3. Aceite os termos.
  4. Escolha Just Me.
  5. Clique em Next.
  6. Escolha a pasta de instalação.
  7. Clique em Install.
  8. Aguarde a instalação.
  9. Clique em Finish.

Pronto! O Python e todas as bibliotecas já estarão instalados.

3. Criando uma pasta para os projetos

Crie uma pasta para armazenar seus trabalhos. Exemplo:

C:\AnaliseDados

Dentro dessa pasta ficarão:

C:\AnaliseDados
    "arquivo".csv

4. Criando um arquivo BAT para abrir o Jupyter

Dentro da pasta do projeto: clique com o botão direito → Novo → Documento de Texto. Renomeie para:

abrir_jupyter.bat

Edite o arquivo e coloque o seguinte conteúdo:

@echo off

cd /d "%~dp0"

jupyter lab

pause

Salve. Agora basta dar dois cliques nesse arquivo. O navegador abrirá automaticamente o JupyterLab.

5. Caso o comando não funcione

Se aparecer a mensagem:

'jupyter' não é reconhecido como um comando...

Abra o menu Iniciar, pesquise por Anaconda Prompt e execute:

jupyter lab

6. Abrindo um projeto

Quando o Jupyter abrir, aparecerá uma tela semelhante a um explorador de arquivos. Navegue até a pasta onde está seu CSV, por exemplo AnaliseDados.

7. Criando um Notebook

Clique em Python 3. Será criado um novo arquivo, por exemplo Untitled.ipynb. Renomeie para:

Analise.ipynb

8. O que é uma célula?

O Notebook funciona por células. Cada célula pode conter código Python, texto, tabelas ou gráficos, e pode ser executada individualmente.

9. Executando uma célula

Digite:

print("Olá Mundo")

Depois pressione Shift + Enter. Resultado:

Olá Mundo

10. Importando bibliotecas

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

11. Carregando um arquivo CSV

Supondo que exista um arquivo league.csv na mesma pasta do Notebook, digite:

df = pd.read_csv("league.csv")

12. Visualizando os dados

df.head()      # primeiras linhas
df.info()      # informações gerais
df.describe()  # estatísticas

13. Limpando os dados

df.isnull().sum()   # verifica valores nulos
df = df.fillna(0)   # substitui valores nulos por 0

14. Agrupando dados

Calcular a média da taxa de vitória por Lane:

df.groupby("Lane")["WinRate"].mean()

15. Criando um gráfico

sns.barplot(
    data=df,
    x="Lane",
    y="WinRate"
)

plt.title("Win Rate por Lane")
plt.show()

O gráfico aparecerá logo abaixo da célula.

16. Inserindo textos

Clique em uma célula, depois em Cell → Cell Type → Markdown. Agora escreva:

# Introdução

Neste trabalho iremos analisar os dados do League of Legends.

Execute a célula. Ela ficará formatada como um documento.

18. Fluxo recomendado para Análise de Dados

  1. Importar bibliotecas.
  2. Carregar o arquivo CSV.
  3. Visualizar os dados.
  4. Explorar a estrutura da tabela.
  5. Identificar problemas.
  6. Limpar os dados.
  7. Organizar os dados.
  8. Realizar análises.
  9. Criar gráficos.
  10. Escrever as conclusões.

19. Estrutura recomendada do Notebook

Introdução
    ↓
Importação das bibliotecas
    ↓
Leitura do CSV
    ↓
Exploração dos dados
    ↓
Limpeza dos dados
    ↓
Tratamento dos dados
    ↓
Análise dos dados
    ↓
Gráficos
    ↓
Conclusão

Seguindo essa estrutura, seus projetos ficarão organizados, fáceis de entender e semelhantes aos utilizados por profissionais da área de Ciência e Análise de Dados.
